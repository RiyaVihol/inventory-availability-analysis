 Project Summary

 Problem

Customers may see products as available even when actual inventory is unavailable, which can lead to cancelled orders and customer dissatisfaction.

 Analysis Approach

The project combines business analysis documentation with data analysis:

Requirements → Excel analysis → SQL analysis → Tableau dashboard → Insights → Recommendations → UAT/Traceability

 Key Findings

- S03: 15/22 (~68%) of total inventory discrepancy.
- 4K Monitor + Tablet Air: 18/22 (~82%) of total discrepancy.
- Wireless Mouse has the highest order quantity but is not a major discrepancy product.
- All 5 cancelled orders in the analysed data were associated with an out-of-stock reason.
- S03 has the highest data-error count (3).

 Recommendation

Prioritize inventory reconciliation at S03, focusing first on 4K Monitor and Tablet Air. Review inventory records, physical counts, and inventory-update/synchronisation processes for the affected product-store combinations.
